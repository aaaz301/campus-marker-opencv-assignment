# 装甲板检测

一个基于 OpenCV 的装甲板检测程序，从视频帧中识别蓝色灯条，并根据灯条之间的几何关系判断是否为装甲板目标。

项目使用 C++17 实现，使用 CMake 构建，适合用于视觉识别、目标检测和机器视觉实验。

## 功能概述

- 读取视频文件
- 对图像进行 B - R 通道差分，提取蓝色灯条
- 过滤噪声和无效候选区域
- 识别单个灯条，并计算其长度、宽度、角度等特征
- 组合左右灯条，判断是否构成装甲板
- 在结果图像中绘制灯条框、装甲板轮廓、对角线和中心线
- 支持调试窗口和结果视频保存

## 处理流程

1. **图像二值化**：计算蓝色通道与红色通道的差值（B − R），再要求蓝色通道本身足够大，提取蓝色灯条。
2. **形态学处理**：用竖向的小核做闭运算，连接灯条上的小断点，同时不让灯条变粗。
3. **灯条筛选**：根据面积、长度、长宽比、填充率和倾斜角度过滤候选区域，并计算每个灯条的旋转矩形和上下端点。
4. **配对筛选**：对灯条两两组合，依次检查长度相似度、平行程度、间距比例、中心连线方向，并排除中间夹着其他灯条的组合。
5. **数字检查**：检查两根灯条之间的区域是否有足够多的亮像素（白色数字），排除"灯条 + 空支架"或跨板的误配。
6. **结果绘制**：在原图上标出灯条和装甲板，保存为视频。

## 环境要求

- Linux / Ubuntu 22.04
- CMake 3.10+
- C++17 编译器
- OpenCV 4.x

Ubuntu 下安装依赖：

```bash
sudo apt update
sudo apt install build-essential cmake pkg-config libopencv-dev
```

```text
.
├── CMakeLists.txt

├── src/
```

## 编译

在项目根目录执行：

```bash
cmake -S . -B build
cmake --build build -j
```

编译完成后，可执行文件位于：

```text
build/armor
```

修改代码后，只需再次执行 `cmake --build build -j`。只有增删源文件或修改了 `CMakeLists.txt` 时，才需要重新执行 `cmake -S . -B build`。

## 运行

**请在项目根目录下运行**，这样输出文件会落在项目的 `output/` 文件夹里。

使用默认视频（`example1.mp4`）：

```bash
./build/armor
```

指定视频文件：

```bash
./build/armor example1.mp4
```

处理整个文件夹（路径含通配符时要加引号）：

```bash
./build/armor "videos/*.mp4"
```

关闭 GUI 窗口，仅处理并保存视频（在没有桌面环境的服务器上必须使用）：

```bash
./build/armor example1.mp4 --nogui
```

GUI 模式下按 `ESC` 可跳过当前视频。

## 输出说明

程序会在**运行命令时所在的目录**下创建 `output` 文件夹，并把处理后的视频保存为：

```text
output/<视频名>_out.mp4
```

结果视频里的标记含义：

| 标记 | 含义 |
|---|---|
| 绿色框 | 通过筛选的灯条 |
| 红色四边形 | 装甲板轮廓（由左右灯条的四个端点围成） |
| 黄色对角线 | 两条对角线的交点即装甲板中心 |
| 青色线 | 左右两根灯条中心的连线 |
| 紫色点 | 装甲板中心 |

GUI 模式下还会显示：

- `result`：处理结果窗口
- `binary`：二值化灯条窗口
- `tune`：可调参数窗口（trackbar）

## 参数说明

**可在 `tune` 窗口中实时调整的参数：**

| 参数 | 含义 | 默认值 |
|---|---|---|
| `diff(B-R)` | 蓝色差值阈值（`diffThresh`） | 30 |
| `blueMin` | 蓝色通道最低值 | 80 |
| `digitGray` | 判断数字像素的灰度阈值 | 75 |

**写在代码 `Params` 结构体里的参数（需要修改后重新编译）：**

| 参数 | 含义 | 默认值 |
|---|---|---|
| `minBarLength` | 灯条最小长度（像素） | 10 |
| `minLenWidthRatio` / `maxLenWidthRatio` | 灯条长宽比范围 | 2 ~ 20 |
| `maxBarTilt` | 灯条偏离竖直方向的最大角度 | 40° |
| `minLenSimilarity` | 两灯条长度比下限（装甲板侧转时一长一短） | 0.4 |
| `maxAngleDiff` | 两灯条最大角度差 | 15° |
| `minDistRatio` / `maxDistRatio` | 两灯条中心距离 ÷ 平均长度的范围 | 0.5 ~ 3.2 |
| `minDigitRatio` | 装甲板内部亮像素占比下限 | 0.10 |

## 调参建议

1. 先看 `binary` 窗口：灯条应是完整的白色细条，背景大部分是黑色。
2. 灯条不完整或缺失：降低 `diff(B-R)`。
3. 背景杂点很多：提高 `diff(B-R)` 或 `blueMin`。
4. 灯条检出了但没有配成装甲板：检查 `digitGray`，数字太暗时需要调低；再检查配对相关参数是否太严格。

## 注意事项

- 视频源必须是清晰的图像帧，否则灯条提取可能不稳定。
- 光照条件变化较大时，颜色阈值需要重新调节。
- 本程序依赖装甲板上有亮色数字，且装甲板两侧的两根灯条都能被看到。只能看到一根灯条时无法组成装甲板。
- 本程序更适合标准装甲板目标检测，不一定覆盖所有复杂场景。
