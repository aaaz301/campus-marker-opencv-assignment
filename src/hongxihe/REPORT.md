## 运行方法

```bash
cmake -S src/hongxihe -B build/hongxihe \
  -DCMAKE_BUILD_TYPE=Release
cmake --build build/hongxihe --parallel
./build/hongxihe/marker_recognition \
  data/raw/marker_video.avi \
  src/hongxihe/evidence/hongxihe_marker_result.mp4
```

## 方法概述

程序对每一帧执行以下步骤：

```text
灰度化 → 阈值分割 → 闭运算 → 开运算 → 外部轮廓提取
→ 白色角块筛选 → 四个角块轮廓合并
→ 整体旋转矩形 → 绘制四边形和角点
```

白色角块筛选使用的主要约束为：

- 轮廓面积不小于 40 像素；
- 外接框宽度和高度不小于 8 像素；
- 轮廓面积与外接框面积的填充率位于 0.15～0.85；
- 当候选多于四个时，枚举四个候选的所有组合；
- 根据 L 形方向取外接框对应角作为角块代表点；
- 根据四个代表点的平均值计算整体中心，并检查四个点的相对位置；
- 检查四个代表点是否组成凸四边形；
- 检查四条边的长度是否处于合理范围；
- 将 L 形方向与所在象限的匹配程度加入几何评分；
- 如果存在多组几何结构合理的组合，优先选择几何评分更低的组合，
  评分相同时选择平均轮廓面积更大的组合。

整体中心由四个方向代表点的坐标平均值得到，不再使用外接框中心的
最小/最大坐标中点。中心位置只用于检查四个代表点分别位于左上、右上、
右下和左下象限。中心空置距离阈值不再作为硬性条件，面积也不再作为
四个候选组合的硬性筛选条件；面积仅保留为同等几何结构下的次要排序依据。

## 坐标约定

图像坐标原点位于左上角，向右为 x 正方向，向下为 y 正方向，
单位为像素。每个装甲板候选的角点顺序固定为：

```text
左上 LT → 右上 RT → 右下 RB → 左下 LB
```

## 当前限制与后续改进

- 当前主要绘制一个标志物候选，尚未处理多个目标；
- 当前目标四角点来自四个白色角块轮廓的整体旋转矩形；
- 白色阈值和角块筛选参数仍需结合更多视频进一步调优；
- 当前未实现相机标定、PnP、数字识别和复杂目标跟踪。

## 失败案例与干扰因素

- 当某个 L 形角块被遮挡或只显示一部分时，其轮廓形状和面积会发生
  变化，可能导致单个角块漏检或整体四边形不稳定；
- 光照变化可能使白色区域断裂，影响轮廓提取和 L 形模板匹配；
- 目标离开画面时，程序返回未检测到，不会继续绘制上一帧的目标结果；
- 地面灯光反射可能生成白色候选区域，通常会被 L 形模板和四角几何
 约束排除，但当反射形状接近目标时仍存在误检风险。
