# 必做目标

方法流程、关键参数、失败案例、改进思路和已知限制；

## 方法流程
读取视频，按帧处理
中值滤波去噪
二值化
形态学处理
提取白色轮廓
通过算法得到构成标志物的点集
用凸包和多边形近似得到矩形框标记

## 关键参数
1. 二值化，灰度大于等于200设为255全白。
2. 形态学处理，用了5*5的kernal进行开运算。
3. 多边形近似的epsilon误差设为周长的0.02倍。
4. 用变异系数(CV)判断是否处于同一标志物，其阈值设为2.1

## 失败案例

CV阈值设置不当会导致识别不准确（单个标志物识别不全或同时标记多个标志物）。

经过调参，单个标志物基本识别正确。当存在多个标志物且有一个标志物部分位于画面外时，识别可能不准确。(*)

当多个标志物彼此靠得太近，可能识别错误。

## 改进思路

换一种方法识别在同一标志物的若干点集，询问AI后，可以计算点集到矩形中心的距离，取最大距离与矩形半对角线之比，比值过大则舍弃。通过这个方法可以较好解决问题(*)。这个思路未实现。

## 已知限制

标志物必须为白色正方形。
二值化阈值固定，拍摄环境的光照应当适宜。
不能识别过远的目标。
多个标志物之间不能太近。

# 相机标定与位姿估计
## 方法流程

手工录入标定板参数：7*7圆点格，相邻圆点圆心间距40mm。

每80张帧选取一张关键帧，使用calibrateCamera进行相机标定，得到内参矩阵和畸变系数。

选取一个角的圆点作为原点，建立右手空间系，演示视频中红线为x轴，绿线为y轴，蓝线为z轴。用相机标定计算出的内参矩阵和畸变系数，计算得到标志物坐标系相对相机坐标系的偏移量(mm)和旋转量(degree)。其中相机坐标系为向右为x轴正方向，向下为y轴正方向，沿光轴向外为z轴正方向。

## 关键参数

相邻圆点圆心间距40mm，每80张帧选取一张关键帧。
RMS 重投影误差: 0.952479 px
有效帧数: 80
内参矩阵:
[2402.243509333798, 0, 701.9043416284735;
 0, 2402.758081444998, 555.113091662805;
 0, 0, 1]
畸变系数:
[-0.06075502818975532, -0.06531366132524626, -0.001590318213557377, -0.001012748754750621, 2.44418750067833]

fx = 2402.24, fy = 2402.76, cx = 701.904, cy = 555.113
