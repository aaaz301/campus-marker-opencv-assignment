# 112 帧修复与性能优化成果说明

本目录存放 112 帧漏检修复及性能优化后的运行成果（带框视频、逐帧数据、配置与报告）。

## 修复成果

- **检出**：1676 帧测试视频上达到 1088 帧检出（原 976 帧）；
- **112 帧假阴性**：112/112 全部恢复，原 976 帧 raw 四角逐值不变，指定恢复集合外新增 0；
- **性能**：Release 两轮实测均值 7.67/7.48ms，最大 27.80/26.06ms，超 33ms 均为 0（30 FPS 设计目标）。
