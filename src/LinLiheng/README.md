# 校内赛标识物识别

这个示例用 C++17 和 OpenCV 逐帧处理 `videos/` 中的视频。

## 构建与运行

需要 CMake 3.16 及以上版本、C++17 编译器和支持 MP4 读写的 OpenCV 4 开发包。仓库中的 MP4 使用 Git LFS；克隆后若看到的是文本指针，请先运行 `git lfs pull`。 //呃直接复制粘贴的

```bash
cmake -S . -B build
cmake --build build -j
./build/marker_demo videos/data_raw_marker_video.avi results
```

每段视频会输出以下内容，全部与输入视频保持相同帧率，由 OpenCV 的 `VideoWriter` 直接写为 `mp4v` 编码的 MP4。程序不再进行外部转码；新生成的视频可能无法在 VS Code 内置播放器中直接打开，可使用支持 MPEG-4 Part 2 的播放器查看。

## 流程与参数

1. **去噪**：5x5 高斯滤波。
2. **二值化**：将原图像直接转换为灰度图，并用`128`作为阈值二值化处理，区分图像黑白区域。
3. **形态学**：再用 `erode` 后接 `dilate` 实现 3×3 开运算、去除小亮点；用 `dilate` 后接 `erode` 实现 3×3 闭运算、连接小断点。
4. **轮廓与L形**：寻找外轮廓，筛选图像中六边形围成的封闭L型区域，DS指出，可能存在因标识物运动导致出现的毛刺，使封闭图形处理出的轮廓边数变化，使得严格按照`approx.size()==6`筛选会遗漏部分L型，因此筛选边数在`4`到`6`之间的图形。
5. **寻找凹点**：使用`cv::convexHull`函数寻找筛出L型中的凸出的直角顶点，排除得L型唯一的凹点，将四个凹点作为标识物识别的四个顶点。
6. **绘制矩形**：将四个凹点按其相对这四个点的中心的角度排序，依次连接这四个点，得到最终标识识别物的矩形框。

## 存在问题

出于未知原因，在样例视频识别过程中有几帧标识物出现但是识别失败，通过目测法推测可能与标识物运动过程中的颠簸有关。
