# 校内赛标志物识别

使用 C++ 和 OpenCV，通过亮度分割、轮廓几何筛选和相对位置检查，识别校内赛标志物，输出目标区域及四个角点。

## 1. 开发环境

- 系统：Ubuntu 22.04.5 LTS（WSL）
- 编译器：GCC / G++ 11.4.0
- CMake：3.22.1
- OpenCV：4.5.4
- C++ 标准：C++17

## 2. 安装依赖

在 Ubuntu 中执行：

```bash
sudo apt update
sudo apt install build-essential cmake pkg-config libopencv-dev
```

程序运行需要可用的图形显示环境。

## 3. 编译

以下命令均从仓库根目录执行：

```bash
cmake -S src/yuhang -B build/yuhang -DCMAKE_BUILD_TYPE=Release
cmake --build build/yuhang --parallel
```

生成的可执行文件为：

```text
build/yuhang/marker_detector
```

## 4. 运行

从仓库根目录执行：

```bash
./build/yuhang/marker_detector data/raw/marker_video.avi
```

程序逐帧处理输入视频，并显示结果窗口。点击结果窗口后，使用英文输入法按小写 `q` 退出；不提前退出时，程序处理到视频结尾。

缺少视频路径、视频无法打开或没有可读取帧时，程序输出错误提示并以非零状态退出。

## 5. 输出

程序生成的结果视频：

```text
build/yuhang/result.avi
```

重复运行会覆盖同名输出文件。按 `q` 提前退出时，仅保存已处理的帧。

结果画面包含：

- 绿色四边形：发光标志图案的目标区域，不表示整个黑色安装板。
- 红色点：目标的四个近似外角。
- LT、RT、RB、LB：分别表示左上、右上、右下、左下。
- Detected：当前帧通过检测规则。
- Not detected：当前帧未通过检测规则。

角点按 LT、RT、RB、LB 顺序排列。坐标采用原始视频帧坐标系，左上角为原点，x 向右增大，y 向下增大，单位为像素。

## 6. 方法概述

1. 使用 3×3 中值滤波减少孤立噪点。
2. 转为灰度图，以固定亮度阈值提取亮区。
3. 提取外轮廓，通过填充比例和矩形宽高比筛选大 L 形候选。
4. 检查三个候选的相对位置和尺寸。
5. 在估计的右上位置附近收集亮区轮廓点。
6. 从轮廓方向极值中提取四个近似外角。
7. 绘制目标四边形、角点标签和检测状态。

每帧重新计算检测结果，未通过检测时不绘制上一帧的目标框或角点。

具体参数、测试观察和限制见 `REPORT.md`。

## 8. 结果材料

提交视频：

```text
evidence/demo.mp4
```

- 时长：23.805 秒。
- 文件大小：约 6.3 MB。
- 内容：连续帧识别结果、目标四边形、四个角点标签和检测状态。

程序直接输出 MJPG 编码的 AVI。提交视频使用 FFmpeg 转为 H.264 MP4；FFmpeg 仅用于结果材料压缩，不是程序运行依赖。

转换命令：

```bash
ffmpeg -n -i build/yuhang/result.avi -c:v libx264 -crf 23 -preset medium -pix_fmt yuv420p -an -movflags +faststart src/yuhang/evidence/demo.mp4
```

## 9. 已知限制

- 当前要求恰好存在三个大 L 形候选，候选缺失或额外干扰可能导致漏检。
- 固定亮度阈值可能受光照、曝光和强反光影响。
- 布局与角点规则主要适用于目标接近正立的情况，明显旋转和透视变化可能导致失败。
- 右上位置搜索可能收集附近的干扰亮区。
- 标志物被画面边缘截断时，可能返回未检测到。
- 当前未加入跨帧平滑或跟踪。
- 当前程序接收视频文件路径，尚未提供摄像头设备参数。
- 未完成相机标定和位姿估计。
