 操作系统：Ubuntu 20.04 (WSL2)
 编译器：g++ (GCC 9.4.0)
 C++ 标准：C++14
 CMake 版本：3.16.3
 OpenCV 版本：4.2.0
 依赖安装命令：`sudo apt install build-essential cmake libopencv-dev`

在 `src/caoailin` 执行以下命令：
mkdir build
cd build
cmake ..
make

##运行方法
./detect_marker <输入视频路径> <输出视频路径>

## 4. 主要参数说明
* 图像预处理：转为灰度图，采用固定阈值 150 进行二值化，提取高亮区域。
* 形态学处理：使用 20x20 的矩形核进行闭运算，将标志物内部散落的 L 形发光块连接成一个整体。
* 轮廓筛选：按面积降序排序，仅取最大轮廓，面积过滤阈值为 2000 像素。
* 几何约束：长宽比限制在 0.5 ~ 2.0 之间，以适应接近正方形（80mm×80mm）的科技核心 MARK 灯。
* 时序稳定：连续 10 帧未检测到目标，则清空上一帧结果，避免无限复制。
