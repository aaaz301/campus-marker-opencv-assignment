# REPORT – 校内赛标志物识别

## 第一部分：必做任务 — 标志物检测

### 1.1 方法概述

标志物是一个白色正方形面板（测试视频中约 190×190 px），表面印有深色几何图案。在暗色环境中白色面板非常突出。逐帧处理流程：

1. **HSV 白色阈值分割** — `S ≤ 60`（低饱和度）、`V ≥ 140`（高亮度），隔离白色标志物；3×3 形态学开运算去噪。
2. **轮廓提取 + Union-Find 聚类** — `findContours`（`RETR_EXTERNAL`），面积 < 200 px² 丢弃；包围框在 80 px 内的用并查集合并，取面积最大的簇。
3. **尺寸/宽高比验收** — 高度 ∈ [120, 280] px，宽度 ∈ [15, 400] px；完整可见时宽高比 ∈ [0.4, 3.0]，部分可见时 ≥ 0.08。
4. **Canny 边缘密度验证** — 聚类 ROI 内边缘密度 ∈ [0.005, 0.65]，排除空白或过曝区域。
5. **角点提取（双模式）**：
   - **主方法：convexHull + approxPolyDP** — 聚类内所有轮廓点求凸包，多边形逼近（ε = 0.02 × 周长）得到 4 个角点。
   - **后备方法：65×65 闭运算 + minAreaRect** — 闭运算填充内部图案，最大轮廓的 `minAreaRect` 给出角点。
6. **角点排序** — 极角排序得到循环序，上边（中点 Y 最小）确定 LT/RT/RB/LB。
7. **亚像素细化** — `cornerSubPix`（5×5 窗口，30 次迭代，0.01 px 收敛）。轴对齐时（< 10°）强制方形约束。
8. **时域平滑** — 3 帧 Y 中值滤波去尖刺 + 自适应指数低通（静止 α = 0.3，运动 ≥ 5 px/帧时 α = 1.0）。
9. **遮挡容忍** — 检测失败 ≤ 5 帧沿用上一帧；超过 5 帧输出 "NOT DETECTED" 并重置。

### 1.2 检测结果

`data/raw/marker_video.avi`（1676 帧，1440×1080，70.4 FPS）：

- **检测到：1333 / 1676 帧（79.5%）**
- **未检测到：343 帧（20.5%）**

未检测到的帧分属 5 个连续片段，标志物完全不在画面中（LED 关闭）或仅剩边缘 < 15 px 的窄条。

### 1.3 失败案例与限制

1. **LED 关闭** — 无白色像素，无法检测。
2. **部分可见** — < 15 px 时检测失败。
3. **大角度旋转（> ~15°）** — 方形约束关闭，角点精度可能下降。
4. **多目标** — 当前仅取最大簇，不支持多标志物。

### 2.3 三角形角点识别

**问题：** `findCirclesGrid` 对 7×7 对称圆点阵列返回 49 个圆心，但起始角点在不同帧中可能映射到不同的物理角点（4 种旋转方向），导致坐标系原点在不同帧之间不一致。特别是当标定板倾斜时，透视畸变使板面从正方形变为不规则四边形，角点识别更加困难。

**解决方案：** 标定板的黑色边框有一个角向内多了一个黑色斜三角形，使图形不对称。利用该特征识别物理角点，采用以下改进策略提高倾斜/透视情况下的识别率：

**1. 自适应局部格间距（`localCellSizes()`）：**
不再使用全局平均格间距，而是从每个角点的两条相邻边各自计算局部格间距。透视畸变下近侧边长、远侧边短，使用局部间距使采样窗口大小自适应。

**2. 多尺度暗像素采样（`cornerDarkRatio()`）：**
对每个角点，在向外侧 0.3、0.5、0.7 倍局部格间距处分别取窗口统计暗像素比例（< 100），取最大值。多尺度采样能适应不同倾斜角度下三角形在图像中的位置变化。

**3. 严格检测 + 时域宽松回退：**
- **严格模式**：选暗像素比例最高且明确领先的角点。阈值自适应：当透视畸变 > 10%（对边长度差比 > 10%）时，阈值从 1.2× 放宽到 1.1×，因为透视畸变使近侧边框角点也积累暗像素，缩小了三角形角点与次高角点的差距。覆盖 97.6% 的帧。
- **宽松模式 a**：当严格检测失败时，若丢失帧数 < 15，检查上一帧的三角形角点是否仍为当前帧最优（允许 10% 容差）。处理板面旋转过渡帧。
- **宽松模式 b**：当丢失帧数 < 60 时，接受当前帧暗像素比例最高的角点（阈值 1.05×，绝对值 ≥ 15%）。处理板面长时间消失后重新出现的帧。
- 合计覆盖 98.6% 的帧（所有 `findCirclesGrid` 成功的帧均能识别）。

**4. 全部 49 点 PnP（`reorderCenters()`）：**
确定三角形角点后，将 49 个检测圆心重排为物理顺序（LT 在前），使用全部 49 点而非仅 4 个角点进行 `solvePnP`。更多约束点提高了位姿估计精度和鲁棒性，尤其在透视畸变较大时。

**5. 角点排序（`orderCorners()`）：**
三角形角点定义为物理 LT。用叉积法确定相邻角点的 X/Y 方向：若 cross(adj1, adj2) > 0，则 adj1 为 RT（X 轴方向）、adj2 为 LB（Y 轴方向）。对角角点为 RB。

**物理边框角点检测：** 沿对角线方向从网格角点向外扫描，检测白色（板面 > 120）到暗色（边框 < 80）的亮度跳变。使用局部格间距确定扫描范围，适应透视畸变。

### 2.4 位姿估计

**方法：** 每帧检测 49 个圆心 → 识别三角形角点 → 确定 4 个角点的物理顺序（LT/RT/RB/LB）→ 匹配已知 3D 坐标 → `cv::solvePnP`（迭代法）估计 6 自由度位姿。

**标志物坐标系、相机坐标系和单位：**

| 坐标系 | 定义 |
|--------|------|
| 标定板坐标系 | 原点在三角形角点（物理左上角圆心）；X 向右（列方向，朝向 RT），Y 向下（行方向，朝向 LB），Z 朝向相机（右手系）。单位：米。 |
| 相机坐标系 | OpenCV 约定：X 右，Y 下，Z 前（朝向场景）。 |
| tvec | 标定板原点在相机坐标系中的位置（米）。 |
| rvec | 标定板坐标系到相机坐标系的旋转向量（Rodrigues 形式）。 |

**位姿结果的坐标轴方向：**
- X 轴（红色）：标定板平面上向右，指向 RT 方向
- Y 轴（绿色）：标定板平面上向下，指向 LB 方向
- Z 轴（蓝色）：标定板法线方向，朝向相机

**距离单位：** 米（m）。

### 2.6 误差与稳定性观察

- **标定 RMS 0.076 px** — 亚像素精度，说明圆心检测和拟合质量高。
- **98.6% 检测率** — 严格识别 97.6% + 时域回退 1.0%。所有 `findCirclesGrid` 检测成功的帧（98.6%）均能正确识别三角形角点并估计位姿。剩余 1.4% 的帧是 `findCirclesGrid` 本身失败（板面完全出画或严重遮挡），无法检测圆点阵列。
- **坐标系原点一致性** — 通过三角形特征，所有帧的坐标系原点固定在三角形角点（物理左上角），消除了 `findCirclesGrid` 对称阵列的起点歧义。
- **顶点标注** — 视频中 4 个顶点用不同颜色标注：LT（红）、RT（黄）、RB（绿）、LB（蓝），并显示标签文字。同时绘制黑色边框轮廓。
- **每帧独立估计** — 无时域滤波，每帧的位姿独立计算，可作为精度验证。

### 2.7 已知限制

1. **`findCirclesGrid` 失败** — 板面完全出画、严重遮挡或运动模糊时圆心检测失败（1.4% 的帧）。这是当前系统的唯一失败来源，三角形角点识别已不再受限。
2. **远距离** — 格间距 < 25 px 时三角形检测的暗像素比例差异变小，但多尺度采样和时域回退已基本解决此问题。
3. **平面歧义** — 共面点的 PnP 在特定朝向下可能存在位姿歧义。使用全部 49 点（而非仅 4 角点）已大幅缓解此问题。
4. **时域回退限制** — 连续丢失超过 60 帧后不再使用时域回退，避免板面大幅旋转后沿用错误的角点顺序。
5. 当目标板倾斜或者侧着对着相机的角度比较大时，有可能识别不到。
